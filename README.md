# LinuxDo 智能降噪过滤器

面向 [linux.do](https://linux.do) 的 Tampermonkey 用户脚本。在「标签 / 板块过滤」之上增加**标题内容分诊**：把没打「纯水 / 人工智能」标签的低信息量主题（豆包式求助、账号咨询、短问句等）识别并过滤，同时用**保护信号**（开源、教程、实测、避坑……）确保优质项目帖不被误杀。

- 零外部请求：纯本地判定，只改写页面数据，不向任何服务器发送内容
- 可解释：每条被过滤的主题都显示命中原因，支持单帖豁免
- 可调：预设、词库、自定义规则均可在页面内编辑、导入导出

## 特性

| 能力 | 说明 |
| --- | --- |
| 硬信号 | 板块（自动含子板块）、标签（任一 / 不含） |
| 软信号 | 标题分诊：提问词、账号/消费主题词、优质保护词，按命中数量作为条件 |
| 保护优先 | 命中保护信号（或保护高亮规则）的帖子不会被过滤；纯水等硬标签规则除外 |
| 无闪烁 | 改写首屏预载数据 + 拦截 fetch/XHR，翻页也不闪 |
| 抽屉 | 顶栏「已过滤 (n)」查看被过滤列表、命中原因、一键豁免 |
| 调试 | 设置里打开「调试日志」，控制台输出每条判定 |

## 安装（Tampermonkey）

> 本脚本只针对 Tampermonkey 适配。

1. 安装 Tampermonkey 扩展：
   - Chromium 系（Chrome / Edge / Brave 等）：浏览器商店搜索安装
   - Firefox：addons.mozilla.org 搜索安装
   - Android：Firefox 或 Edge 安装 Tampermonkey
2. **开启用户脚本权限（Chromium 138+ 必做，否则脚本会静默不执行）**：
   - 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
   - 找到 Tampermonkey，点「详情」
   - 打开 **允许用户脚本（Allow User Scripts）** 开关；旧版本浏览器则是打开右上角「开发者模式」
3. 安装脚本，任选其一：
   - 安装链接（推荐，支持自动更新）：
     `https://raw.githubusercontent.com/EveSunMaple/linuxdo-smart-filter/main/dist/linuxdo-smart-filter.user.js`
   - 或打开 Tampermonkey 仪表盘 → 实用工具 → 导入，粘贴上面的链接 / 拖入本地 `dist/linuxdo-smart-filter.user.js` 文件
4. 打开 linux.do 生效。脚本安装时会请求 `GM_getValue / GM_setValue / GM_registerMenuCommand / GM_addStyle`。

## 使用

- **顶栏按钮**：`已过滤 (n)` 打开抽屉查看被过滤的主题（标题 / 板块 / 标签 / 回复 / 命中原因 / 豁免按钮）；齿轮打开设置。找不到站点顶栏时会显示为右下角浮动按钮。
- **设置 → 规则**：开关预设、新建规则、调整顺序、恢复默认预设。
- **设置 → 词库**：编辑提问词 / 主题词 / 保护词，词库是所有预设共用的信号来源，是调优的首选入口。
- **设置 → 数据**：导出 / 导入配置、管理豁免名单、复制备份。
- **Tampermonkey 菜单命令**：打开设置 / 查看已过滤列表 / 暂停降噪。
- 修改规则、词库后点击「刷新页面」完全生效。

## 预设说明（默认开启，可单独关闭）

| 预设 | 逻辑 | 备注 |
| --- | --- | --- |
| 纯水标签硬过滤 | 标签含 纯水 / 灌水 / 无意义 | 硬过滤，保护词也不能豁免它 |
| 推广/福利标签过滤 | 标签含 公益推广 / 广告 / 抽奖 | 命中保护词时放行 |
| 开发调优·求助降噪 | 板块=开发调优（含子板块）且提问词 ≥ 2 | 重点解决「开发调优全是求助帖」 |
| AI标签·求助降噪 | 标签含 人工智能 / 快问快答 且提问词 ≥ 1 | |
| 账号/消费咨询降噪 | 提问词 ≥ 1 且主题词 ≥ 1 | 如账号、额度、KYC、拼车类咨询 |
| 主题词堆叠降噪 | 主题词 ≥ 2 且标题 ≤ 24 字 | 捕捉「中国护照 claude kyc」这类无问句短帖 |
| 短问句降噪（谨慎） | 板块=开发调优/搞七捻三、提问词 ≥ 1 且标题 ≤ 14 字 | **默认关闭**，按需开启 |
| 优质信号保护高亮 | 标题命中保护词 ≥ 1 | 永不误杀，绿色高亮 |
| 开源/教程标签保护高亮 | 标签含 开源 / 教程 / 分享 等 | 永不误杀，蓝色高亮 |

判定顺序：**豁免名单 → 硬过滤（纯水等）→ 保护高亮 → 软过滤（命中保护词的帖子跳过）**。

## 自定义规则

设置 → 规则 → 新建规则，条件支持自由组合（全部条件须同时满足）：

- 所属板块（勾选父板块自动包含子板块）
- 标签包含任一 / 不包含
- 标题信号：提问词 ≥ n、主题词 ≥ n、优质词 ≥ n（计数来自词库，按命中的不同词去重）
- 标题长度范围
- 标题正则（每行一条，任意一条命中即可）

例如「过滤带教程标签但其实在问账号问题的帖子」：标签含「教程」+ 提问词 ≥ 1 + 主题词 ≥ 1。

## 误杀了怎么办

1. 打开抽屉，点该帖「豁免此帖」——之后刷新不再过滤；或用「设置 → 数据 → 标题关键词豁免」把标题特征词加进白名单。
2. 更推荐：把该帖标题里的优质特征词（如「实测」「响应式」）补进**保护词库**，以后同类内容都会受保护。
3. 如果某个预设整体偏激进：关掉它，或降低其词库/阈值。所有改动都在设置里可视化完成。

## 常见问题

- **装了没反应？** 先确认 Chromium 138+ 上已打开 Tampermonkey 详情页的「允许用户脚本」开关（见安装第 2 步）。
- **看不到按钮？** 站点导航栏不可用或不可见时，按钮会自动变成右下角浮动按钮；两者都没有的话，在设置里打开「调试日志」并刷新页面，看控制台 `[LD-SF]` 的挂载日志。
- **为什么某帖没被过滤？** 标题没有命中任何信号（默认“宽松上线”策略宁可放过）。可在「设置 → 调试日志」里观察判定结果，再补词库或开「短问句降噪」。
- **软刷新 / 新开页面偶尔出现未过滤的帖子？** 脚本对「预载数据 + fetch/XHR + 渲染后 DOM」三层拦截：正常首屏由预载改写直接过滤；极端情况下（数据已被浏览器缓存、页面未发起请求）会在渲染后由 DOM 兜底立即隐藏，可能有一瞬间的闪现。
- **为什么改完要刷新？** 列表数据在页面加载时就被改写，规则变更需要重新处理数据。抽屉/设置里的按钮都有一键刷新。
- **手机能用吗？** 可以。Android 用 Firefox/Edge + Tampermonkey；抽屉与设置面板已做窄屏适配。

## 开发

```bash
pnpm install
pnpm typecheck   # TS 类型检查
pnpm lint        # Biome 静态检查 + 格式校验
pnpm lint:fix    # 自动修复与格式化
pnpm test        # 语料回归测试（vitest）
pnpm build       # 构建 dist/linuxdo-smart-filter.user.js（可用 --watch）
```

目录结构：

```
src/
  main.ts       入口：装配 App / Host，注册菜单命令
  engine.ts     规则编译与判定（硬过滤 → 保护 → 软过滤）
  classify.ts   标题信号提取（词库命中、问句结尾）
  presets.ts    默认预设规则
  lexicons.ts   默认词库
  store.ts      配置读写（GM 存储）、导入导出
  page.ts       页面上下文识别、板块映射与解析
  intercept.ts  预载改写 / fetch / XHR / DOM 兜底 / 已过滤桶
  ui/           顶栏、抽屉、设置面板、样式
tests/          截图语料回归与引擎单测
```
